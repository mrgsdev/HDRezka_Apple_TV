## Установка

Приложения нет в App Store, его ставят из Xcode на свою Apple TV. Нужен Xcode 26+ и tvOS 18+.

1. Xcode → Settings → Accounts: добавить Apple ID (подойдёт бесплатный Personal Team).
   Если старые сертификаты отозваны: Manage Certificates → «+» → Apple Development.
2. Открыть проект:

   ```bash
   open HDrezkaTV.xcodeproj
   ```

   Swift Package SwiftSoup подтянется автоматически.
3. Target **HDrezkaTV** → Signing & Capabilities: выбрать свой Team. Если Xcode ругается на Bundle ID,
   поменять его на любой свой, например `com.<имя>.hdrezkatv`.
4. Apple TV и Mac в одной сети. На Apple TV: «Настройки → Пульты и устройства → Приложение Remote и устройства».
   В Xcode: Window → Devices and Simulators, Apple TV появится в списке, Pair, ввести код с экрана телевизора.
5. Выбрать Apple TV вверху Xcode и нажать Run (⌘R). Первая установка занимает пару минут.

С бесплатным аккаунтом приложение работает 7 дней, потом нужно снова нажать Run в Xcode (вход, закладки
и Итоги сохранятся). С платным Apple Developer ($99 в год) срок год, и можно ставить через TestFlight.

## Для разработчиков

<details>
<summary><b>Структура проекта</b></summary>

```
HDrezkaTV/
  App/          точка входа, вкладки бокового меню, знакомство при первом входе
  Core/         зеркало, меню сайта (жанры), cookies в Keychain, сессия, прогресс просмотра, вход с телефона
  Network/      RezkaClient: все запросы к сайту
  Parsing/      HTML-парсер (SwiftSoup), декодер ссылок на видео, WebVTT
  Models/       модели данных сайта
  Features/     экраны: Home, Catalog, Collections, Search, Roulette, Stats, Bookmarks, Details,
                Person, Player, Parental, Onboarding, Auth, Settings
  UI/           общие компоненты (постеры, полки, сетка, карточка на постере, цвета)
  Localizable.xcstrings  строки интерфейса: русский (исходный) и английский
```

Все CSS-селекторы собраны в `HDrezkaTV/Parsing/RezkaParser.swift`: если сайт поменяет вёрстку, править нужно там.
Сеть, парсер и модели общие с [версией для Mac](https://github.com/mrgsdev/HDRezka_macOS) (там они лежат
в `REZKA/Shared`), так что исправления стоит переносить в оба проекта.

</details>

<details>
<summary><b>Отладка</b></summary>

- Запросы к сайту пишутся в системный лог (путь, статус, размер, время, без cookies):
  `xcrun simctl spawn booted log stream --predicate 'subsystem == "com.mrgsdev.hdrezkatv"'`
- Аргументы запуска (Scheme → Run → Arguments):
  - `-disableRemoteProgress YES`: не отправлять позицию просмотра на сайт (для тестов);
  - `-dumpHTTP YES` (Debug): сохранять ответы сайта в `Library/Caches/http-debug` для проверки парсера.
- Сайт подвисает на пачках параллельных запросов, поэтому `RezkaClient` пускает не больше 3 одновременно.
- Премиум-качества («1080p Ultra») для бесплатного аккаунта отдаются минутным тизером, поэтому по умолчанию они не выбираются.
- Пустой список сайт отдаёт обычной страницей со статусом 404, и приложение показывает его как пустой, а не как ошибку.

</details>
